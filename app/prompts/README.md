# Prompt Templates

Template prompt AI per fitur, terpisah dari kode Python.

Konvensi yang disarankan:
- Satu file `.md` atau `.txt` per fitur: `journal_insight.md`, `reflection_chat_system.md`, dst.
- Gunakan placeholder seperti `{user_context}` / `{journal_text}` — di-load & di-format saat runtime.
- Versi prompt bisa dikelola lewat penamaan file (`reflection_chat_v2.md`) agar mudah A/B test.
